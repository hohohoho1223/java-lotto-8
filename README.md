# java-lotto-precourse

## 기능 요구 사항

간단한 로또 발매기를 구현한다.

- 로또 번호의 숫자 범위는 1~45까지이다.
- 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
- 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.
- 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래와 같다.
  - 1등: 6개 번호 일치 / 2,000,000,000원 
  - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원 
  - 3등: 5개 번호 일치 / 1,500,000원 
  - 4등: 4개 번호 일치 / 50,000원 
  - 5등: 3개 번호 일치 / 5,000원
- 로또 구입 금액을 입력하면 구입 금액에 해당하는 만큼 로또를 발행해야 한다. 
- 로또 1장의 가격은 1,000원이다. 
- 당첨 번호와 보너스 번호를 입력받는다. 
- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다. 
- 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시키고, "[ERROR]"로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.
  - `Exception`이 아닌 `IllegalArgumentException`, `IllegalStateException` 등과 같은 명확한 유형을 처리한다.

## 구현할 기능 목록

### 입력 관련 기능
- [x] 로또 구입 금액 입력
    - [x] 금액이 1000원 단위 인지 검증
- [x] 사용자 당첨 번호 입력
  - [x] 쉼표(,) 기준으로 숫자 분리 기능
  - [x] 중복 검증
  - [x] 1~45내 범위인지 검증
- [x] 보너스 번호 입력
  - [x] 1~45내 범위인지 검증
  - [x] 당첨 번호와 중복인지 검증
  - [x] 보너스 번호 입력에 대한 검증

### 로또 발행 기능
- [ ] 구입 금액에 따른 로또 발행 수 계산
- [x] 로또 번호 생성 기능 (LottoNumberGenerator)
  - [x] 1~45 범위 내에서 중복되지 않는 6개의 번호 생성 
  - [x] 오름차순으로 정렬하여 반환 기능
- [x] 로또 번호 반환 기능 (Lotto)
- [x] 로또 번호에 대한 유효성 검증 기능 (Lotto)
  - [x] 1~45 범위 검증 기능
  - [x] 중복 검증
  - [x] 번호개수 6개 검증
  
 ### 당첨 결과 계산 기능
- [ ] 사용자의 입력 번호와 당첨 번호 비교
- [ ] 일치 개수에 따라 순위 (1~5등) 판별
  - [ ] 보너스 번호 포함하여 2등 판별 
- [ ] 당첨 통계 계산
- [ ] 총 수익률 계산

### 출력 관련 기능
- [ ] 입력 내역 반환 기능
  - [ ] 구입 금액 입력 내역
  - [ ] 구입 개수 입력 내역
  - [ ] 로또 발행 내역
  - [ ] 보너스 번호 입력 내역
- [ ] 통계 출력 기능
  - [ ] 당첨 개수 반환 기능
  - [ ] 총 수익률 반환 기능 (소수 둘째 자리 반올림)

### 예외처리
- [ ] 입력값이 유효하지 않을 경우 `[ERROR]`로 시작하는 에러 메시지 출력
- [ ] `IllegalArgumentException`, `IllegalStateException` 등 명확한 예외만 사용
